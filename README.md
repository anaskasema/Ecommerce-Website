# Anas Online Shop

متجر إلكتروني عربي متجاوب لعرض الإلكترونيات والهواتف والأجهزة المنزلية. يستخدم المشروع صور المنتجات الموجودة في `img/product` وبيانات الكتالوج من `products.json`.

## المشكلة والحل

كانت صفحة المتجر فارغة تقريبًا، وملفات CSS وJavaScript بلا محتوى، كما كان رابط ملف التنسيق يشير إلى مسار غير صحيح. لذلك لم تكن المنتجات أو وظائف المتجر تظهر.

تم بناء واجهة عربية باتجاه RTL، وربطها ببيانات وصور المشروع، وإضافة البحث والتصفية والترتيب والمفضلة وسلة تسوق تحفظ محتوياتها محليًا في المتصفح. وأُصلح مسار ملف التنسيق وأضيف هذا الدليل لتسهيل تشغيل المشروع ونشره.

## محتويات المشروع

```text
.
├── index.html             صفحة المتجر
├── products.json          بيانات المنتجات وأسعارها وتصنيفاتها
├── README.md              وصف المشروع وطريقة تشغيله
├── css/
│   └── style.css          التنسيق والتصميم المتجاوب
├── javascript/
│   └── main.js            تحميل المنتجات والتفاعلات
└── img/
    └── product/           صور المنتجات المستخدمة في الكتالوج
```

## المتطلبات

لا يحتاج المشروع إلى تثبيت حزم. يكفي متصفح حديث، وتشغيل خادم HTTP محلي لأن المتجر يحمّل `products.json` باستخدام `fetch`.

## تشغيل الموقع محليًا

من مجلد المشروع، شغّل أحد الأوامر التالية:

```powershell
# باستخدام Python
python -m http.server 8000
```

أو باستخدام Node.js:

```powershell
npx --yes http-server -p 8000
```

ثم افتح هذا العنوان في المتصفح:

```text
http://localhost:8000/
```

يمكن أيضًا فتح مجلد المشروع في VS Code وتشغيل إضافة Live Server. لا تفتح `index.html` مباشرة عبر `file://`، لأن المتصفح قد يمنع تحميل ملف المنتجات بهذه الطريقة.

## المزايا

- واجهة عربية RTL متجاوبة مع الجوال وسطح المكتب.
- عرض المنتجات من `products.json` باستخدام صور المشروع.
- البحث والتصفية حسب القسم وترتيب المنتجات حسب السعر أو الاسم.
- قائمة مفضلة وسلة تسوق مع تعديل الكميات والحذف.
- حفظ السلة والمفضلة في `localStorage` على الجهاز.
- نموذج اشتراك تجريبي للنشرة البريدية.

## ملاحظات

- إتمام الطلب وتسجيل الحساب غير مربوطين بخدمات خلفية أو بوابة دفع؛ أزرارهما تعرض رسالة توضيحية فقط.
- الاشتراك بالبريد يعرض تأكيدًا في الصفحة ولا يرسل البيانات إلى خادم.
- العملة المعروضة في الواجهة هي الريال السعودي، ويمكن تعديل الأسعار والمنتجات من `products.json`.

## النشر على GitHub Pages

1. ارفع ملفات المشروع إلى مستودع GitHub.
2. افتح **Settings → Pages** في المستودع.
3. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، واضغط **Save**.
4. بعد اكتمال النشر، سيظهر رابط الموقع في صفحة إعدادات Pages.
